# student_grade_calculator
A simple Python project that calculates student total marks, percentage, and final grade using an absolute grading system.
Student Grade Calculator

My first Python project.

This program calculates a student's total marks, percentage, and final grade based on marks in four subjects.

Subjects

- Mathematics
- Physics
- Programming
- English

Grading System

Percentage| Grade
80% and above| A
70% - 79%| B
60% - 69%| C
50% - 59%| D
Below 50%| F

Technology Used

- Python
- Jupyter Notebook

How to Run

1. Open the Jupyter Notebook.
2. Run the code cells.
3. Enter the student's name and subject marks.
4. View the final result.
